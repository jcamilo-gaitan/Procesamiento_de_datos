# 🐍 Ejercicios de Python 🐍

¡Bienvenido/a a esta colección de cuadernos educativos en **Python**! 🚀

Este directorio forma parte de un repositorio enfocado en el aprendizaje progresivo de programación, desde conceptos básicos hasta programación orientada a objetos.

En estos cuadernos se presentan los temas principales que permiten el uso de Python, cada uno de estos contiene una sección explicativa sobre el tema correspondiente y otra sección de ejercicios resueltos sobre el tema.

---

## 📂 Contenido

Los siguientes cuadernos están organizados por tema para facilitar el estudio:

| Nº | Tema         | Archivo                  | Descripción breve                         |
| -- | ------------ | ------------------------ | -------------------------------------- |
| 01 | Cadenas      | `01-Python-Cadenas`      | Manipulación y operaciones con strings |
| 02 | Tuplas       | `02-Python-Tuplas`       | Uso de tuplas y estructuras inmutables |
| 03 | Listas       | `03-Python-Listas`       | Manejo de listas y métodos principales |
| 04 | Conjuntos    | `04-Python-Conjuntos`    | Operaciones con sets                   |
| 05 | Diccionarios | `05-Python-Diccionarios` | Estructuras clave-valor                |
| 06 | Condiciones  | `06-Python-Condiciones`  | Uso de if, else y elif                 |
| 07 | Bucles       | `07-Python-Bucles`       | Ciclos for y while                     |
| 08 | Funciones    | `08-Python-Funciones`    | Definición y uso de funciones          |
| 09 | Clases       | `09-Python-Clases`       | Programación Orientada a Objetos       |
| ⭐  | Práctico     | `Practico_Bono_1`        | Ejercicios integradores                |

---

## Objetivos de aprendizaje

Estos cuadernos tienen como propósito:

* ✅ Fortalecer los conocimientos sobre fundamentos de Python
* ✅ Desarrollar pensamiento lógico
* ✅ Aplicar conceptos mediante ejercicios prácticos
* ✅ Preparar para proyectos más avanzados en Ciencia de Datos y Desarrollo

---

##  Recomendaciones

Para trabajar con estos cuadernos se recomienda:

* Python 3.8 o superior
* Jupyter Notebook / Jupyter Lab / Google Colab
* Editor de código (VS Code recomendado)

## 📚 Recomendación de Estudio

Se sugiere seguir el orden numérico:

```
01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → Práctico
```

Esto garantiza una progresión lógica de los conceptos.
